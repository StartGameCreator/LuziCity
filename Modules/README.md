# Luzicity Modules

Esta pasta separa os dominios principais da plataforma. A primeira implementacao usa os modelos centrais em `app/Models` para acelerar a fundacao, mas os diretorios dos modulos ja estao prontos para receber controllers, rotas, migrations e services especificos.

Modulos iniciais:

- Admin
- News
- Categories
- Tags
- Users
- Subscriptions
- Advertising
- Social
- Comments
- Likes
- Shares
- Videos
- Podcasts
- Radio
- Live
- RSS
- Search
- AI
- SEO
- Analytics
- Notifications
- Settings
