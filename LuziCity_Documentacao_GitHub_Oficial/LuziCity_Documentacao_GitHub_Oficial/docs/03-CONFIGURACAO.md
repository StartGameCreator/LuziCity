## Regras de segurança

- Nunca versionar `.env`.
- Não imprimir tokens ou segredos em logs.
- Em produção, usar HTTPS e `APP_DEBUG=false`.
- Rotacionar credenciais quando houver suspeita de exposição.
- Manter URLs de callback iguais às cadastradas nos provedores.
