# Fundos Tematicos

Coloque aqui imagens de fundo do site.

Exemplo:

```text
public/images/backgrounds/cidade.jpg
```

Depois, no arquivo `.env`, use:

```env
LUZICITY_BACKGROUND_IMAGE=images/backgrounds/cidade.jpg
LUZICITY_BACKGROUND_OPACITY=0.34
```

Use valores menores de opacidade quando a foto for muito forte, por exemplo `0.20`.
